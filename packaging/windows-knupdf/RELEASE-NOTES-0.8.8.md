KnuPdf 0.8.8 시험판입니다. 0.8.7에서 바뀐 점만 적었습니다. 기능 전체는 [0.8.0 안내](https://github.com/Donoban-kang/knupdf/blob/main/packaging/windows-knupdf/RELEASE-NOTES-0.8.0.md)를 보세요.

## 바뀐 점

- **인쇄가 선명해지고, 인쇄 중 프로그램이 닫히지 않습니다**: Windows 인쇄 방식을 바꿨습니다.
  - 이전: Windows의 PDF 그리기 기능(Direct2D)이 쪽 전체를 한 해상도로 그림으로 바꿔 인쇄했습니다. 300dpi에서는 글자가 흐렸고, "이미지로 인쇄 600dpi"도 같은 과정을 다시 거쳐 흐렸습니다. 600dpi로 인쇄하거나 연달아 인쇄하면 프로그램이 닫히기도 했습니다.
  - 이제: 화면에 보이는 것과 같은 KnuPdf 렌더러로, 프린터 해상도(300~600dpi, 사무용 복합기는 보통 600dpi)에 맞춰 쪽을 띠 모양으로 나눠 그립니다. 그린 띠는 한글 같은 프로그램이 쓰는 표준 인쇄 방식(GDI)으로 프린터에 보냅니다. 한 번에 띠 하나만 처리하므로 메모리를 적게 쓰고, 빈 부분은 보내지 않습니다.
  - 용지 크기, 방향, 매수, 양면, 컬러/흑백 설정은 이전과 같이 적용됩니다. "이미지로 인쇄"는 체크하지 않아도 됩니다.
  - 확인한 범위: 문제가 났던 복합기(DocuCentre-VII C3373, PCL 6)에서 인쇄되고 글자가 선명한 것을 확인했습니다. 다른 프린터에서는 아직 확인하지 못했습니다.
  - 알아둘 점: 600dpi로 그리기 때문에 쪽 수가 많은 문서는 프린터로 보내는 데 이전보다 시간이 더 걸릴 수 있습니다.

## 내려받기 (Windows 10/11, 64비트)

| 파일 | 용도 |
|---|---|
| `KnuPdf-0.8.8-windows-x64-setup.exe` | 설치 프로그램. 이전 버전이 설치된 PC에서는 덮어서 설치하면 됩니다. |
| `KnuPdf-0.8.8-windows-x64-portable.zip` | 설치 없이 쓰는 휴대용판. 압축을 풀고 `KnuPdf.exe`를 실행합니다. |

설치 파일은 코드 서명이 없어 Windows Defender가 잘못 탐지할 수 있습니다. 그럴 때는 휴대용 zip을 쓰세요.

## 파일 확인값 (SHA-256)

```
SETUP_SHA  KnuPdf-0.8.8-windows-x64-setup.exe
ZIP_SHA  KnuPdf-0.8.8-windows-x64-portable.zip
```
