KnuPdf 0.8.5 시험판입니다. 0.8.4에서 바뀐 점만 적었습니다. 기능 전체는 [0.8.0 안내](https://github.com/Donoban-kang/knupdf/blob/main/packaging/windows-knupdf/RELEASE-NOTES-0.8.0.md)를 보세요.

## 바뀐 점

- **마크다운(MD)으로 내보내기 추가**: PDF 내보내기 ▸ "마크다운 (.md)". AI에 넣거나 검색하기 좋도록 제목(#), 문단, 목록, 표를 살려 씁니다. 그림은 빼고 `[그림]` 표시만 남기며, 쪽이 바뀌는 곳에 `<!-- page N -->` 표시를 넣습니다. 병합된 표 칸은 풀어서 씁니다(세로로 병합된 칸은 각 행에 다시 적어 행마다 뜻이 통하게 함). 스캔 쪽은 0.8.4의 Windows 한국어 문자 인식을 거쳐 글자로 들어갑니다.
- **표 칸 글자 섞임 수정(한글 변환에도 적용)**: 칸 사이 간격이 좁은 표에서 옆 칸의 글자가 한 칸으로 몰리던 문제("120 | 명 하반기")를 고쳤습니다.
- **줄바꿈된 문장이 끊기던 문제 수정(한글 변환에도 적용)**: 줄이 "(월)까지…"처럼 괄호로 시작하면 새 문단으로 나뉘던 문제를 고쳤습니다. 이제 (1), (가) 같은 목록 기호만 새 문단으로 봅니다.
- **보안 업데이트**: rustix(RUSTSEC-2026-0486) 등 의존 라이브러리를 올렸습니다.

## 내려받기 (Windows 10/11, 64비트)

| 파일 | 용도 |
|---|---|
| `KnuPdf-0.8.5-windows-x64-setup.exe` | 설치 프로그램. 이전 버전이 설치된 PC에서는 덮어서 설치하면 됩니다. |
| `KnuPdf-0.8.5-windows-x64-portable.zip` | 설치 없이 쓰는 휴대용판. 압축을 풀고 `KnuPdf.exe`를 실행합니다. |

설치 파일은 코드 서명이 없어 Windows Defender가 잘못 탐지할 수 있습니다. 그럴 때는 휴대용 zip을 쓰세요. 스캔 문서의 인식 결과는 반드시 원본과 대조해 확인하세요.

## 파일 확인값 (SHA-256)

```
SETUP_SHA  KnuPdf-0.8.5-windows-x64-setup.exe
PORTABLE_SHA  KnuPdf-0.8.5-windows-x64-portable.zip
```
