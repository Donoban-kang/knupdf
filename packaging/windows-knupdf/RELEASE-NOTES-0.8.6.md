KnuPdf 0.8.6 시험판입니다. 0.8.5에서 바뀐 점만 적었습니다. 기능 전체는 [0.8.0 안내](https://github.com/Donoban-kang/knupdf/blob/main/packaging/windows-knupdf/RELEASE-NOTES-0.8.0.md)를 보세요.

## 바뀐 점

- **스캔 문서가 거칠게 보이던 문제 수정**: 스캐너·복합기로 만든 PDF에서 글자 획이 끊기거나 구두점이 깨져 보이던 문제를 고쳤습니다(예: 물결표 `~`가 `…`처럼 보임). PDF가 "부드럽게 그리기"를 따로 지정하지 않은 그림을 줄여서 보여줄 때 점을 몇 개씩 건너뛰며 골라 그려서, 줄 폭보다 가는 획이 사라지는 것이 원인이었습니다. 이제 줄여서 그릴 때는 항상 주변 점을 평균해 그립니다. 확대해서 볼 때는 예전과 같습니다.
  - 확인한 범위: 스캔 문서 1건과 이를 바탕으로 만든 변형 14종(1비트·그레이·컬러, 해상도 100~600ppi)을 0.4~3배로 비교했습니다. 글자 문서·벡터 문서·확대된 그림은 화면이 달라지지 않았습니다. 실제 Windows 화면과 다른 장비의 스캔 문서로는 아직 확인하지 못했습니다.
  - 알아둘 점: 해상도가 매우 높은 스캔 쪽(600ppi급)은 처음 그릴 때 최대 약 40% 더 걸릴 수 있습니다(약 0.8초 → 1.1초).

## 내려받기 (Windows 10/11, 64비트)

| 파일 | 용도 |
|---|---|
| `KnuPdf-0.8.6-windows-x64-setup.exe` | 설치 프로그램. 이전 버전이 설치된 PC에서는 덮어서 설치하면 됩니다. |
| `KnuPdf-0.8.6-windows-x64-portable.zip` | 설치 없이 쓰는 휴대용판. 압축을 풀고 `KnuPdf.exe`를 실행합니다. |

설치 파일은 코드 서명이 없어 Windows Defender가 잘못 탐지할 수 있습니다. 그럴 때는 휴대용 zip을 쓰세요. 스캔 문서의 인식 결과는 반드시 원본과 대조해 확인하세요.
